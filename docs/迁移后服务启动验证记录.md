## 附 2：全栈 launchd 托管（2026-09-03，TRAE 回收问题最终解决）

- 根因：TRAE 沙箱会话 SIGTERM 回收后台 java；launchd(/usr/bin/java=OpenJDK25) 与 hadoop getSubject 不兼容；MySQL 零日期值
- 修复：launchd + JDK11 绝对路径 + DB env + `zeroDateTimeBehavior=convertToNull`（7 服务连接串）
- plist：`deploy/com.temporedata.guard.{main,platform,security,data,police,agent,dev}.plist`（KeepAlive + bootstrap）
- 验证：7 进程 launchd 托管 Started（320s），3 分钟后仍存活（不再回收），**完整回归 44/44**
- 复现命令：`launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.temporedata.guard.main.plist`（6 服务同法）
