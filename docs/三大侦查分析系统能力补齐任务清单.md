## 0. 现状与差距速览

| 系统 | 已有（可直接用） | 关键缺口 |

| 涉网新型行为分析 | SimilarityService 串并案、FraudAnalysisService 涉诈卡、FundFlowService 资金、ContactAnalysisService 通联、SpatialTemporalService 时空、舆情规则、文书模板、Agent 工具 fraud_probe/sentiment/fund_flow | 无涉网行为数据模型与采集；相似案件=标签+n-gram 全表扫描；涉诈结论硬编码规则；舆情无语料 |

## 阶段 P1：涉网新型行为分析

### N1-1 涉网行为数据模型 + 采集 API
- 新增表 `temporedata_guard_cyber_event`：id、entityId(关联人员)、eventType(LOGIN/TRADE/CHAT/POST/TRANSFER…)、eventTime、terminal(APP/PC)、ip、ipRegion、domain/appName、account、amount、payload JSON(证据)、evidence、density(默认 CONFIDENTIAL)、tenantId、createTime；索引 (entityId,eventTime)、(ip,eventTime)、(account)。
- 新增 `M/police/cyber/`（新子包）：entity + repository + `CyberEventService`（批量导入/查询/按 entity 时间线/按 ip-account 关联）+ `CyberEventController`（`POST /api/cyber/events` 批量、`GET /api/cyber/entities/{id}/timeline`、`GET /api/cyber/ip/{ip}/entities`）；全部 @Audit + BaseResponse + LoginUser。
- 配套：导入接口内置 N1-2 的要素抽取钩子；上传 CSV 时可复用 FileService 自动推断模式登记血缘（P0-4）。
- 验收：批量导入 100 条 → timeline/ip 关联查询正确；密级过滤生效（低密级用户见脱敏账号）。

### N1-2 案件要素抽取 + 新型手法知识库
- 新增表 `temporedata_guard_case_modus`：id、modusCode/Name（杀猪盘/刷单/跑分…）、keywords JSON、category、level、description、createTime。
- `M/police/cyber/service/CaseFeatureExtractor.java`：从案件描述/证据文本抽取要素（时间/金额/渠道/话术特征/IP 归属），规则+正则表驱动（同 SentimentAnalysisService 词表模式），输出要素结构；
- `ModusMatcher`：案件要素 vs 知识库关键词评分匹配 → 打 modus 标签（写 EntityLabel，labelType 可复用 BEHAVIOR/CASE）。
- 验收：录入 2 个样例案件 → 自动匹配出 modus 标签；知识库条目 CRUD 页面（admin）。

### N1-3 相似案件升级（索引化 + 行为特征）
- 改动 `M/police/network/service/SimilarityService.java`：
  - 去 `findAll()` 全表扫描（L46）：先按"标签交集+类型过滤+时间窗"预筛；
  - 特征向量（L66-83）增加：modus 标签、资金流向方向、涉网行为时段分布、涉案工具（账号/IP）；
  - 阈值>0.4 持久化 SAME_CASE 逻辑保留（:55）；结果允许 UI 确认（复用 Agent.vue persistSeries 模式）。
- 验收：库内 5 万实体量级下单次检索 <3s；同 modus 案件召回优先。

### N1-4 涉诈研判结论可配置化

- 验收：修改一条规则生效后研判结论变化；原涉诈卡 UI/Agent 工具输出兼容。

### N1-5 舆情语料化（可选，P2 前置）
