## 二、资源管理域

### 2.1 计算集群（/cluster）
- **功能**：集群注册与管理
- **字段**：集群名称、类型（Spark Standalone/YARN/Kubernetes）、Master URL、主机地址、端口、节点数、状态、Agent 状态
- **操作**：新建（类型→连接参数）→ 列表 → 编辑/删除/添加计算节点

### 2.2 数据源（/datasource）★ 插件化
- **类型下拉**（`/api/datasource/plugins` 驱动）：MySQL / H2 / PostgreSQL / ClickHouse / Iceberg 湖仓 / Kafka 事件流（每项带能力提示）
- **动态表单**：按类型切换字段——数据库↔命名空间、Kafka 免用户名/密码、端口自动默认（MySQL 3306/CH 8123/Kafka 9094/Iceberg 9000）
- **列表列**：名称、类型（品牌标签）、主机、端口、库/命名空间、插件能力徽标（查询/写执行/测试/元数据/快照/主题）、状态（已连接/已断开）
- **操作**：编辑 / 测试连接（弹窗提示 + 刷新状态）/ 元数据面板（按插件动态列：JDBC 表/Kafka topic/Iceberg 快照/CH 表）/ SQL 查询预览（SQL 输入 → 动态结果表格，CH 预置 police_analysis 示例）/ 删除

### 2.3 驱动管理（/driver）
- 驱动名称/数据库类型/版本/驱动路径/创建时间；上传驱动 jar + 删除

### 2.4 计算容器（/container）
- 容器名称/类型（Docker/Kubernetes）/所属集群/镜像/CPU 核数/内存(MB)/启动命令/状态/创建时间；新建（类型→集群→资源规格）→ 启停/删除

### 2.5 资源中心（/resource）★ 文件 + 血缘
- **上传**：拖拽上传（jar/zip/tar.gz/csv 等）→ **上传即血缘**（自动解析文件名/表头 → 推断目标表 → 自动登记 FILE→表 LOAD 边，提示"已自动生成血缘关联"）
- **列表列**：文件名称、原始名称、文件大小（B/KB/MB/GB）、文件类型、创建时间
- **打开预览**：CSV/TXT/JSON/LOG → 文本渲染；图片 → base64 显示；PDF → iframe；其他 → 提示下载
- **下载**：带认证 Blob 下载（修复直链 401）
- **血缘**：行内「血缘」→ 链路弹窗（方向标签 加载/导出 + 关联对象 + 说明）；「登记血缘」→ 目标表 + 方向（文件→表入湖 / 表→文件导出）

## 三、数据研发域

### 3.1 数据开发 / 工作流（/workflow）★ DAG 编排
- **列表**：名称/状态（在线/离线）/Cron/描述；新建/编辑/删除/执行/调度配置/执行历史
- **DAG 画布**（@vue-flow）：节点拖拽/连线（成功/失败/总是条件边）/撤销重做/复制/适应画布/校验错误条
- **节点类型**（品牌徽标）：SQL 查询、Spark SQL、Shell 脚本、Python 脚本、DataX 同步、条件分支、子工作流、依赖检查、HTTP 调用、邮件通知、数据质量、**湖仓同步**（源→Iceberg）、**分析加载**（→ClickHouse）
- **节点配置面板**：类型/数据源/脚本（按类型占位符）/Spark 配置/HTTP 参数/**数据范围校验**（scopeSql 自动注入 WHERE/AND，危险写操作无范围拒绝）/质量参数/优先级/失败策略/重试
- **调度**：Cron 表达式 + 启用开关；执行：异步 + 节点级执行记录（状态/耗时/错误）
- **保存**：DAG 变更标记 → 保存 DAG

### 3.2 湖仓管理（/lakehouse）★ 湖仓
- **概览卡**：Warehouse 路径、湖仓表（police.track_flow_daily）、快照数、数据行数
- **快照列表**：快照 ID/快照时间（毫秒格式化）/操作（**时间旅行读取**——按快照回溯历史）
- **数据预览**：动态列表格（region/stat_date/renci/guiji）
- **追加写入**：JSON 数组 → 写入（生成新快照）→ 自动刷新
- **操作**：初始化表/刷新/**注册为数据源**（创建 ICEBERG 数据源）

### 3.3 实时计算（/realtime）
- 任务名称/数据源类型（品牌标签：MySQL CDC/PostgreSQL CDC/Kafka/Socket）/SQL/最近启动时间/状态；新建→启停→删除

### 3.4 全局变量（/globalvar）
- 变量名/变量值/描述 CRUD（工作流/作业引用）

### 3.5 函数仓库（/funcrepo）
- 函数名称/类型（UDF/UDAF/UDTF）/语言（Java/Python/Scala）/状态/描述；新建（语言→类型→脚本）→ 启用停用 → 删除

### 3.6 依赖合集（/dependency）
- 依赖包（名称/类型/配置/描述）管理

### 3.7 发布审批（/approval）
- 标题/申请人/作业流 ID/描述/状态（待审/通过/驳回）/创建时间；详情 → 通过/驳回

### 3.8 引擎作业（/engine）★ 模板 + 配额
- **Spark 作业页签**：名称/主类/JAR 路径/参数/状态（DRAFT/READY/RUNNING/SUCCESS/FAILED/DRY_RUN）；新建/编辑/执行/日志/终止
- **Flink 作业页签**：名称/并行度/状态；同操作
- **作业模板页签**（湖仓 5 类卡片）：Spark→Iceberg 入湖、Spark 湖仓加工、Spark→ClickHouse、Flink 流式入湖、湖仓导出——每卡（引擎徽标 + 名称 + 说明 + 「从模板创建」→ 参数表单 → 生成作业）
- **资源配额页签**：Executor 上限/内存上限(GB)/执行时长上限(分钟)/并发上限 + 保存（提交强制校验，超限拒绝）

### 3.9 数据接入（/ingestion）
- **接入任务**：名称/数据源类型（DB/CSV/API）/目标表/状态/时间；新建/编辑/执行/删除
- **CDC 实时采集链路卡**：链路状态/断点位点统计/实时质量统计 + 「发布演示事件」（binlog→Kafka→湖仓联调）+「采集对账」（源库 vs 湖仓行数）+「刷新」
- **位点表格**：采集位点（中文：轨迹流动聚合表 增量 + 原文副行）/位点值/最近事件时间/更新时间

| 链路 | 界面入口 → 终点 |
