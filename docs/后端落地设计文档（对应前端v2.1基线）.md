## 二、已实现 API（直接复用，前端已对接）

### 2.1 认证与用户
| 端点 | 说明 | 前端使用 |
|---|---|---|
| POST /api/auth/login | 登录 → {token, user{username, roles, density}} | 登录分流 |
| GET /api/user/me | 当前用户信息 | 个人中心 |

### 2.2 管理员核心域（全量已实现）
数据源插件化（/api/datasource + plugins/meta/query/test）、工作流（/api/workflow + execute/schedule）、湖仓（/api/lakehouse init/append/read?snapshotId/snapshots）、CDC（/api/ingestion/cdc demo/status/offsets/reconcile）、质量（/api/quality + check/realtime）、血缘（/api/lineage overview/graph/impact/path/cycles/heat/rebuild + /api/meta/lineage/impact）、元数据（/api/meta + unified/sync·list）、引擎（/api/engine spark/flink/templates/quota）、资源/文件（/api/resource + lineage/register·lineage；/api/file upload/list/download/preview）、集群/驱动/容器（/api/cluster /api/driver /api/container）、安全（/api/security/audit /api/security/level /api/sensitive /api/permapproval /api/blacklist）、系统（/api/tenant /api/role /api/org /api/settings /api/license /api/passwordless /api/notify）、服务（/api/services + test/approve、/api/apilog、/api/report、/api/form）、警务（/api/entitymaster /api/entitygraph /api/intelligence /api/watch /api/track）、Agent（/api/agent chat/config/model-policy）、消息/个人（/api/message /api/mydata /api/user）。

### 2.3 复用约束
- 用户端复用页（情报/图谱/预警/目录/我的数据/API/报表/表单/指标/消息/个人/Agent）**不加新接口**，仅按用户权限与密级在既有接口响应中过滤/脱敏（后端侧由权限内核统一处理）。

## 三、待新增 API（用户端 v2.1 缺口，详细设计）

### 3.1 权限四接口（主应用，P0）
| 端点 | 请求 | 返回模型 | 说明 |
|---|---|---|---|
| GET /api/auth/me | - | {userId, username, tenantId, orgId, roles, dataScopes, securityLevel, workspace:"admin"/"user", projectScopes} | 前端工作台兜底 + 权限刷新 |
| GET /api/auth/permissions | - | List\<String\>（扁平权限编码） | 填充 permission store |
| GET /api/auth/menus | - | [{group, icon, children:[{path,title,permission}]}] | 按角色过滤（管理员/用户两套） |
| GET /api/auth/data-scopes | - | {scopeType, orgIds[], projectIds[]} | 数据范围声明 |

### 3.2 用户工作台（主应用，P0）
`GET /api/user/workbench` → `{todos, projects:[{id,name,level,status}], alerts:[{level,text,time}], recentSearches[], applyStatus[], stats:{todo,project,data,apply}}`

### 3.3 对象研判（警务服务，P0）
| 端点 | 参数 | 返回 |
|---|---|---|
| GET /api/intelligence/entity/{entityId} | - | 画像：{name,type,level,labels[],maskFields{phone,idcard...},cases[],riskTags[]}（密级不足→403 文案，不暴露存在性） |
| GET /api/intelligence/entity/{entityId}/graph | depth=1-5 | 授权范围内图谱（复用 graph 结构） |
| GET /api/intelligence/entity/{entityId}/track | range | 轨迹（脱敏） |

### 3.4 线索中心（警务服务，P0）
| 端点 | 参数 | 返回 |
|---|---|---|
| GET /api/clue | projectId?, level?, status?, page | 线索分页 |
| POST /api/clue | {title, level, source, projectId?, description} | 线索 |
| PUT /api/clue/{id} | {status, remark} | 流转（含加入专案） |

### 3.5 专案中心（警务服务，P1）★ 核心新增
| 端点 | 说明 |
|---|---|
| GET/POST /api/project | 我的专案列表/创建（name/level/description/leader） |
| GET/PUT /api/project/{id} | 专案详情/更新（成员可见） |
| GET/POST /api/project/{id}/objects | 专案对象（entityId/type/role/evidence） |
| GET/POST /api/project/{id}/clues | 专案线索 |
| GET/POST /api/project/{id}/tasks | 专案任务（assignee/deadline/status/result） |
| GET /api/project/{id}/graph | 专案图谱（对象范围） |
| GET/POST /api/project/{id}/reports | 专案报告关联 |
| GET /api/project/{id}/activity | 专案动态（操作流水） |
| POST /api/project/{id}/member | 成员管理（LEADER/ANALYST/VIEWER） |

权限：`project:view`（成员）/ `project:update`（ANALYST+）；**专案上下文**：请求头 `X-Project-Id` → 数据查询/图谱/Agent 自动叠加专案范围。

### 3.6 受控数据查询（研发服务，P0）
| 端点 | 请求 | 返回 | 校验链 |
|---|---|---|---|
| GET /api/data/catalog | keyword?, type? | 授权数据目录（含密级/授权状态） | dataasset:view |
| GET /api/data/catalog/{id} | - | 数据详情（概览/字段/质量/血缘/权限/使用） | dataasset:view |
| GET /api/data/query/options | - | 可查询数据+字段（字段级授权） | dataasset:query |
| POST /api/data/query | {table, fields[], conditions[]} | 结果 + masked 标记 | 授权→范围→字段→密级→安全 SQL→脱敏→审计 |
| GET /api/data/query/history | page | 本人查询记录 | 本人 |

**安全 SQL 约束**：白名单表（授权 catalog）/ 白名单字段 / 参数化条件 / 默认 LIMIT 200；**禁止任意 SQL**。

### 3.7 数据服务（数据服务，P1）
`GET /api/service/api`（已授权 API 列表 + 密级 + 状态）· `GET /api/service/api/{id}`（详情：定义/权限/日志/血缘）· 测试调用复用 `POST /api/services/{id}/test`。

### 3.8 成果中心（研发服务，P1）
| 端点 | 说明 |
|---|---|
| GET/POST /api/report | 我的报告列表/创建（title/type/projectId/securityLevel） |
| GET /api/report/{id} | 报告详情（结论+证据 JSON） |
| POST /api/report/{id}/generate | AI 辅助生成（Agent 编排证据）→ 生成任务 |
| GET /api/report/tasks | 生成任务列表（status/progress/error） |
| POST /api/report/{id}/export | 导出（report:export + 审批链 + 审计 + 脱敏） |

### 3.9 我的（安全服务/主应用，P0-P1）
| 端点 | 说明 |
|---|---|
| POST /api/apply | 数据申请发起（type: 访问/导出/跨单位/临时 + target/purpose/project/deadline） |
| GET /api/apply/mine | 我的申请（status: 草稿/待审/审批中/通过/驳回/过期） |
| POST /api/apply/{id}/approve·reject | 审批（复用 permapproval 通道，P1） |
| GET/POST/DELETE /api/favorite | 收藏（targetType: ENTITY/DATA/API/REPORT） |
| GET /api/favorite/mine | 我的收藏 |
| GET /api/user/ops | 我的操作（本人行为日志，时间范围） |

### 3.10 全局搜索（主应用，P0）
`GET /api/search?keyword=&types=` → 聚合 {entities, cases, clues, data, apis, projects}（各类型按权限/密级过滤 + 脱敏 + 每类上限 10）。

## 四、权限内核（zy-common 新增，P0）

| 组件 | 实现 |
|---|---|
| @RequirePermission("dataasset:export") | 注解 + AOP 拦截（无权限 403） |
| @MaskField | 响应字段脱敏拦截器（zy_sensitive_field 规则 × 调用方 securityLevel） |
| DataScopeGuard | 查询条件注入（tenant/org/project/self，按 dataScopes） |
| DensityGuard | 数据级 ≤ 用户级校验（现有 AiDensityGuard 泛化） |
| AuditInterceptor | 敏感操作留痕（查询/导出/Agent 工具/申请审批） |

**上下文**：LoginUser 扩展 orgId/dataScopes/securityLevel/projectScopes；请求头 X-Project-Id → 当前专案。
