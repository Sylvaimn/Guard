### 3.2 拆分服务（独立进程 + Nacos 注册 + 网关前缀路由）
| 服务 | 端口 | Nacos 名 | 承载能力 | 关键依赖 |

| 安全服务 | 8090 | temporedata-guard-service-security | 分类分级/敏感/审计/审批/消息/黑名单/变更追溯 | security 域全包 |
| 数据服务 | 8092 | temporedata-guard-service-data | 接口服务/报表/表单/数据源(plugin) | data 域 + common |

**扫描边界设计**（包结构域重组后）：
- 主应用全包扫描；拆分服务精确 scanBasePackages（防 bean 依赖链膨胀）
- 事件监听条件化：`app.audit.listener.enabled`（审计）/ `app.lineage.enabled`（血缘）仅主应用开启 → 拆分服务免背 LineageService/AuditLogService 依赖链
- 湖仓（common.lakehouse + hadoop-common/avro/mapreduce）仅主应用 + 研发服务承载

## 五、核心功能模块详细设计

### 5.1 数据源插件化（data.datasource）
- **SPI**：`DataSourcePlugin`（type()/aliases()/capabilities()/test/query/execute/meta/release）
- **注册**：`PluginRegistry` 按 type+aliases 索引；4 插件：JDBC（aliases MYSQL/H2/POSTGRESQL）、ClickHouse、Iceberg、Kafka
- **能力矩阵**：CLICKHOUSE[query/execute/test/meta] · ICEBERG[query/meta/snapshots] · JDBC[query/execute/test/meta] · KAFKA[test/meta/topics]
- **API**：/api/datasource/plugins（能力声明）· /{id}/meta（元数据：CH 表/Kafka topic/Iceberg 快照/JDBC 表）· /{id}/query·execute·test
- **连接管理**：JdbcConnectionManager 连接池 + CryptoUtil 密码加解密

### 5.2 工作流引擎（dev.workflow）
- 13 类节点：SQL/SPARK_SQL/SHELL/PYTHON/DATAX/CONDITION/SUB_WORKFLOW/DEPENDENCY/HTTP/EMAIL/DATA_QUALITY/**LAKEHOUSE_SYNC/ANALYSIS_LOAD**
- **WorkflowExecutor**：拓扑排序执行 + 边条件（SUCCESS/FAILURE/ALWAYS）+ 重试/超时/失败策略
- **数据范围校验（applyScopeGuard）**：DELETE/UPDATE 无 WHERE 拒绝；scopeSql 自动注入 WHERE/AND（防越权）
- 调度：Quartz（主应用单飞）+ Cron + 执行历史（工作流/节点级）
- 湖仓节点：源数据源 SQL → Iceberg 入湖 / 查询 → ClickHouse 分析层

### 5.3 CDC 实时采集（dev.ingestion）
- **链路**：binlog 事件 → Kafka(zy-cdc) → 消费者（主应用 `CdcIngestionListener`）→ Iceberg 湖仓 append
- **并发消费**：`RealtimeQualityListener`（zy-quality 组，流式校验 → zy_quality_check REALTIME）+ 断点位点（zy_ingestion_offset）
- **对账**：/api/ingestion/cdc/reconcile（源库 zy_analysis vs 湖仓行数 + diff + SYNCED/MISMATCH）
- **演示**：/api/ingestion/cdc/demo 发布模拟事件（2 行昌平区）端到端联调

### 5.4 质量模块（dev.quality）
- 规则：NOT_NULL/UNIQUE/RANGE/CUSTOM + 目标表/列/表达式 + 调度执行
- 检查落库：zy_quality_check（result JSON + durationMs + errorMsg）
- **实时质量**：REALTIME: 前缀规则，CDC 流式行级校验（字段完整性/数值范围/阈值），/api/quality/check/realtime 最近 50 条

### 5.5 血缘模块（dev.lineage）
- 节点：TABLE（T: 前缀全局共享）/ TASK（J:{tenant}:{TYPE}:{name}——SYNC/INGESTION/QUALITY/WORKFLOW/**API**/**FILE**）/ COLUMN
- 边：INCLUDES/CONSUMES/PRODUCES/FLOWS_TO/DERIVED_FROM/**LOAD/EXPORT**
- **跨层血缘**：接口测试/审批 → zy-lineage 事件 → KafkaLineageListener → collectApiLineage（表→CONSUMES→API）
- **资源血缘**：collectResourceLineage（FILE 节点 + LOAD/EXPORT 边，幂等：task_id+edge_type 先删后建）+ 上传自动推断（文件名/表头匹配统一目录+已知表列映射）+ 登记持久化 table_id/source_type
- **rebuild**：全量重建（元数据表→sync/ingestion/quality/workflow→资源→manual→字段级），资源边由持久化关联恢复
- **分析 API**：graph（三方向遍历，TABLE 跨租户共享 + LOAD/EXPORT 入图）/ impact / path / cycles / heat / search
- **缓存**：LineageCacheService（Redis 优先，类型化反序列化，TTL 5min，重建即 clear）

### 5.6 元数据模块（dev.meta）
- 采集：各数据源插件 meta() → zy_meta_table/column
- **统一目录**：MetaUnifiedService.syncAll → zy_meta_unified（datasource_name/source_type/item_name/item_type/extra）跨 MySQL/CH/Iceberg/Kafka 聚合
- SQL 血缘解析：SqlLineageParser（JSqlParser）→ INSERT...SELECT 表间血缘 + 字段映射

### 5.7 湖仓（common.lakehouse）
- LakehouseService：HadoopCatalog（本地 warehouse）+ GenericAppenderFactory + Parquet 写入
- init/append/read(snapshotId 时间旅行)/snapshots + 注册 ICEBERG 数据源
- 工作流湖仓节点 + CDC 入湖 + 湖仓管理 API

### 5.8 引擎作业（dev.engine）
- SparkJob/FlinkJob：提交器（spark-submit 命令构建 + 沙箱）+ DRY_RUN（无集群时提交计划）
- **作业模板**：EngineTemplateService 5 类（Spark 入湖/湖仓加工/→CH/Flink 流式入湖/湖仓导出）+ 占位符替换 + 一键创建
- **资源配额**：ResourceQuotaService（zy_resource_quota：Executor/内存GB/时长/并发）+ 提交前校验（超限拒绝，日志+异常）

### 5.9 资源与文件（common.resource / common.file）
- 文件：上传（StorageService 抽象：Local/S3）→ zy_file；预览（文本/图片/PDF/binary 按扩展名）；下载（认证）
- 资源：zy_resource（血缘三字段）；血缘登记/查询；上传自动生成资源 + 血缘

### 5.10 Agent 助手（agent.agent）
- 对话编排：工具意图（analysisAgent.tryAnalyze：entity_search/graph_expand/track_query/watch_status）→ LLM/规则
- **AiModelGateway**：OpenAI 兼容 /chat/completions（Bearer apiKey）+ 场景路由（small/large/sql）+ 密级守卫（AiDensityGuard：INTERNAL 以下拦截）+ 降级链
- 记忆：EntitySlotTracker 指代消解（会话槽位，空 sessionId 防护）+ zy_ai_memory
- 配置：AgentConfig（provider/baseUrl/apiKey/model/temperature/enabled）+ 多级模型策略（角色/案件场景）
- 规则兜底：无配置时内置规则应答（提示配置入口）

### 5.11 可观测性
- Prometheus scrape 8 targets（主应用 + 6 服务 actuator）
- Grafana 面板：平台总览 + 警务业务（ai_chat_total 等埋点）
- 审计：zy_audit_log + 行为日志 + 变更审计

## 六、关键技术机制

| 机制 | 设计 |
|---|---|
| 事件总线 | EventBus 接口：direct（本地）/ kafka 两实现；topic：zy-task/zy-alert/zy-lineage/zy-cdc/zy-quality（与表前缀策略一致一期沿用 zy-*）；消费组按用途隔离（guard-server / -cdc / -quality） |
| 统一响应 | BaseResponse{code,msg,data} + GlobalExceptionHandler（BusinessException 400 / 其他 500 全量日志） |
| 认证 | JWT（zqy_token）+ Spring Security + LoginUser（tenantId/density 密级）+ 免密登录（警务通/短信/CA） |
| 密级体系 | INTERNAL < CONFIDENTIAL < SECRET < TOP_SECRET；跨层传播（湖仓/API 继承上游密级），工具按密级授权 |
| 缓存 | LineageCacheService 双模式（Redis → 本地 TTL 回退）+ 类型化反序列化 |
| 存储抽象 | StorageService（Local 默认/S3 可选，storage.type 切换） |
| 湖仓 | HadoopCatalog 本地 warehouse + Iceberg ACID/快照/时间旅行；cwd 相关路径问题 → 启动绝对路径参数 |
| 保留字规避 | MySQL 保留字（sql/database/schema/type）实体列反引号转义 + ALTER 补列 |
| 启动容错 | SchemaMigrationRunner 跳过已知 DDL 错误（非致命） |

## 七、安全与合规

- 认证授权：JWT + 角色 + 数据范围（本单位/本部门/专案内）
- 数据分级：L1 绝密 - L4 公开；敏感列脱敏（接口按调用方密级）
- 审计：登录/行为/操作审计 + 变更审计 + 接口日志 + 黑白名单
- 防越权：工作流数据范围校验（危险写拦截）、Agent 工具密级守卫、湖仓/API 密级继承
- 资源配额：租户级作业资源限额（防资源滥用）
- 密码策略：复杂度/失败锁定/会话超时
